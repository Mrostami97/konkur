# استخراج سؤال از PDFهای کنکور

ابزار بیرونی (خارج از سایت) برای تبدیل PDF دفترچه‌های کنکور به پیش‌نویس سؤال با متادیتای آزمون.
سایت در زمان اجرا هیچ AI صدا نمی‌زند؛ خروجی این ابزار فقط پیش‌نویس برای بازبینی است
(طبق `AGENTS.md`: Staging → Validate → Review → Publish).

> PDFها، تصاویر صفحه و نتایج (`work/`) هرگز وارد مخزن عمومی نمی‌شوند (`.gitignore`).

## نصب

```bash
cd tools/pdf-question-extractor
python3 -m venv .venv && source .venv/bin/activate   # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

## مراحل

### ۱) فهرست‌برداری و متادیتا
```bash
python -m kx inventory "/مسیر/پوشه‌ی/PDFها"
```
- همه‌ی PDFها (با زیرپوشه‌ها) اسکن می‌شوند، فایل‌های کاملاً تکراری علامت می‌خورند و `work/manifest.csv` ساخته می‌شود.
- از روی نام پوشه/فایل حدس زده می‌شود: سال، مقطع (ارشد/دکتری)، نوع آزمون (سراسری/آزاد/آزمایشی)، رشته، نوع سند (سؤال/کلید).
- **`manifest.csv` را در Excel باز کنید و ستون‌ها را کامل/اصلاح کنید.** این متادیتا به تک‌تک صفحه‌ها و سؤال‌ها چسبانده می‌شود.
  - `doc_kind`: `questions` | `answer_key` | `questions_and_key` | `solutions` | `other`
  - `key_pdf_id`: اگر کلید آزمون در فایل جداست، `pdf_id` فایل کلید را اینجا بنویسید.
  - `skip`: برای کنار گذاشتن فایل `yes` بنویسید.
- اجرای دوباره‌ی `inventory` (مثلاً بعد از اضافه‌کردن فایل) ویرایش‌های شما را حفظ می‌کند.

### ۲) تبدیل صفحه‌ها به تصویر
```bash
python -m kx render            # پیش‌فرض 300 DPI
```

### ۳) خواندن صفحه‌ها — یکی از دو راه (یا هر دو برای مقایسه)

**الف) دستی با چت ChatGPT (با اشتراک خودتان):**
```bash
python -m kx manual
```
آدرس `http://127.0.0.1:8765` را باز کنید. برای هر صفحه: تصویر را داخل ChatGPT بکشید، «کپی دستور» را بزنید و بچسبانید،
پاسخ ChatGPT را در کادر بچسبانید و ذخیره کنید. پاسخ با schema چک می‌شود؛ اگر خراب باشد پیغام می‌دهد.
کار قابل ادامه است: هر وقت برگردید از صفحه‌ی بعدیِ انجام‌نشده شروع می‌شود.

> خودکارسازی سایت ChatGPT (ربات مرورگر) عمداً پیاده نشده: خلاف قوانین OpenAI است و حساب مسدود می‌شود.

**ب) خودکار با API:**
```bash
export OPENAI_API_KEY=...
python -m kx api --model <نام-مدل-بینایی> --limit 20     # اول آزمایشی روی ۲۰ صفحه
python -m kx api --model <نام-مدل-بینایی>                # بقیه
```
خروجی ساختاریافته (JSON Schema سخت‌گیر) دارد، خطاها را تا ۴ بار تکرار می‌کند و قابل ادامه است.

**چند بار خواندن برای دقت بیشتر:** هر «تولیدکننده» (مدل API یا `--producer` متفاوت در حالت دستی) نتیجه‌ی جدا ذخیره می‌کند.
اگر یک صفحه را با دو مدل مختلف بخوانید، مرحله‌ی بعد آن‌ها را فیلد به فیلد مقایسه می‌کند.

### ۴) ادغام و گزارش بازبینی
```bash
python -m kx merge --primary chatgpt-ui
```
- `work/out/<pdf_id>.json`: سؤال‌های هر آزمون با متادیتا، گزینه‌ها، کلید، شکل‌ها و منبع (فایل، sha256، صفحه).
- `work/out/all_questions.jsonl`: همه‌ی سؤال‌ها، یکی در هر خط.
- `work/out/media/`: شکل‌ها با وضوح بالا از PDF اصلی برش داده می‌شوند.
- `work/out/report.csv`: برای هر سؤال `needs_review` و علت‌ها:
  - `producers_disagree:...` — خواندن‌ها در این فیلدها فرق دارند
  - `options=[...]` — تعداد/شماره‌ی گزینه‌ها درست نیست
  - `no_answer_key` / `answer_key_conflict`، `confidence_low`، `uncertain_parts`
  - `duplicate_number`، و شماره‌های جاافتاده در `number_gaps` فایل JSON
  - `single_reading` — فقط یک بار خوانده شده (تأیید متقابل ندارد)
